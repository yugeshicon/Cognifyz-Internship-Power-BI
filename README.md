# Cognifyz Power BI Internship

This repository contains the tasks completed during the **Cognifyz Power BI Internship**.

The project focuses on **investment data analysis, business intelligence, and interactive dashboard development** using **Power BI**. The tasks involve data exploration, visualization, and dashboard design to generate meaningful insights from an investment survey dataset.

---

## Task 1: Data Exploration & Summary

### Question
Explore the investment survey dataset and summarize key statistics.

### Key Features
- Import the dataset into Power BI.
- Perform exploratory data analysis.
- Calculate average age, investment preferences, and savings objectives.
- Create charts to visualize summary statistics.

### Expected Outcome
- Learn exploratory data analysis techniques.
- Understand summary statistics.
- Generate meaningful business insights.

---

## Task 2: Gender-Based Analysis

### Question

- Learn comparative analysis.
- Generate actionable insights.
